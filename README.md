# Student Management System

A student management application built using Python.

## Features
- Add student records
- View student records
- Search for students
- Update student details
- Delete student records

## Technologies Used
- Python

## How to Run
1. Install Python.
2. Download or clone this repository.
3. Open the project folder in VS Code.
4. Run your Python file.

## Purpose
This project was developed to practise Python programming fundamentals and build a simple student management application.
